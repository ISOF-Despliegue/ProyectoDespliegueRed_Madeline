# ProyectoDespliegueRed_Madeline
Repositorio para el proyecto que abarca las EEs Despliegue de Software y Desarrollo de Sistemas en Red, conteniente del proyecto que se usará para ambas, ya que el frontend (cliente rico de Java) también se mostrará ára Despliegue de Software.

## Objetivo general
El proyecto se enfocará en una API que empleará bases de datos para servir como repositorio centralizado de información de la serie de Metroid, creada por Nintendo, y que comprende principalmente datos de los videojuegos desde 1986 hasta 2025 con el objetivo de ayudar a novatos y veteranos de la serie, así como poder brindar información relevante para el desarrollo de aplicaciones con base en los datos presentados (como, por ejemplo, una herramienta de optimización de rutas para speedrunners).

## Stack tecnológico
### Presentación
Capa de presentación en JavaFX.

### Frontend
Cliente rico en Java.

### Backend
API Gateway en nginx.
Servicios en Node.js.

### Persistencia de datos
Bases de datos en MongoDB (una por servicio, excepto multimedia).
Carpeta pública para multimedia.
